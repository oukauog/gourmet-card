## 3. 選択の計算の規則（`src/lib/shopSelection.ts`）

- **状態**: 選んだ店の id の配列（選んだ順）
  - 選択モードは `HomeScreen` の中の状態だけで、URL・履歴・設定・一覧のモジュール変数の記憶には入れない
  - タブ・条件・並び順を変えても残る
  - 「キャンセル」と送れた時に全部外れる
- **表示中** = 今のタブ・今の条件で画面に出ているタイル
- **表示中をすべて選ぶ**: 表示中のうち選んでいない店を足す
- **表示中をすべて外す**: 表示中の店だけ外す（表示の外の選択は残る）
- **ボタンの切り替え**: 表示中が1件以上あって全部選ばれている時は「外す」、そうでなければ「選ぶ」。表示中が0件なら出さない
- **表示外の数**（「うちN店は今の表示の外」）= 選んだ店のうち、表示中に無いもの（別のタブ・条件で外れた店）
- **送る順** = 両タブの全店を**今の並び順**（`listShops({ sort })` の結果＝一覧の読み込み結果の順）で並べ、その中で選んだ店だけを残した順
  - 選んだ順ではない
  - 例: 新しい順で「新しい店」（手札）・「中の店」（行きたい）・「古い店」（手札）の時、どの順に選んでも「新しい店 → 中の店 → 古い店」
  - ファイル名の先頭の店もこの順の最初
- 一覧を読み直して無くなった店の id は、数にも送る対象にも入れない（`existingSelection`）

## 4. 375px 幅での「選ぶ」の置き場所

- 測った結果（題名の高さと、上部バーの右端）
  - 390px: 上部バーに「グルメカード・2列にする・選ぶ・メニュー」が1行に収まる（高さ 52px、右端 374px）
  - **375px: 題名「グルメカード」が2行に折り返し、上部バーの高さが 60px になった（1行に収まらない）**
- そこで仕様どおり、**幅が 390px 未満の時だけ**「選ぶ」を**件数の行（並び順の左）**に置いた（CSS の `@media (max-width: 389px)` で、上部バーの「選ぶ」を隠し、件数の行の「選ぶ」を出す）
  - 390px 以上では件数の行の「選ぶ」は出ない
  - 375px でも上部バーの高さは 52px のまま
  - 既存のボタンの文言・大きさは変えていない
  - スクリーンショットは `02-topbar-375.png` と `07-375-filtered.png`
- 件数の行の見え方
  - 選択モード中と 390px 未満では、項目が途中で折れないようにした（はみ出す時は項目ごと次の段へ）
  - 選択モード中の「表示中をすべて選ぶ」は、件数の行の2段目に出る（`05-select-hidden.png`・`08-375-selecting.png`）
  - 最初の作りでは、絞り込み中に「4件（11件中）」「条件を解除」「表示中をすべて選ぶ」「新しい順」がそれぞれ2行に折れて読みにくかったので、こうしました
- 390px 以上・選択モードでない時の件数の行は、今までと同じ見た目です

## 5. タイルの見た目

- **選んだタイル**

  - 右上にアクセント色（#d9480f）の塗りの丸と、白いチェック
- **選んでいないタイル**: 右上に白い縁の空の丸（黒 12% の地と、細い影）。明るい写真の上でも見える
- **大きさ**: 3列は直径 24px、2列は 28px
- **写真なしのタイル**: 同じ丸が淡い地の上に出る（`03-select-3cols.png` の「写真なしの店」）
- 店名・☆の位置と見た目は同じ
- **帯**
  - 画面下に固定。下端は `env(safe-area-inset-bottom)` を考慮
  - 選択モード中は一覧の下の余白を 120px＋安全域に増やし、最後の行が帯に隠れない（`04-select-2cols-bottom.png`）

## 6. 送る

- 帯の「3店を送る」→ 工事8の送るシート（題名「3店を送る」）。準備は `exportShopsCard(送る順, .zip)`
- **送れた時**（共有の完了か「ファイルとして保存」）は、シートが閉じた時に選択を外して普通の一覧に戻る
  - 共有の完了はシートが自動で閉じる
  - 保存は「閉じる」操作で閉じた時
  - タブ・条件・スクロール位置はそのまま（e2e で「行きたい」タブのままを確認）
- **共有メニューを閉じた（AbortError）時・送らずにシートを閉じた時**は、選択モードのまま・選択も残る
- 最後のバックアップ日時は記録しない（シートの `onDelivered` はこの画面の「送れた」印だけに使う）

## 13. 保留・質問

1. **375px の置き場所の境目を 390px にした**
   - 「幅が 390px 未満なら件数の行」にしています（測った結果、375px では題名が折れ、390px では収まったため）

2. **件数の行に「選ぶ」を置く狭い画面で、今のタブが0件の時**は件数の行ごと出ないため、「選ぶ」も出ません。もう一方のタブに店があれば、そちらのタブで押せます
3. **帯のボタンが0店の時の文言は「送る」**（押せない）にしました。仕様の例は「3店を送る」だけだったため、0店の時の文言は決めました
