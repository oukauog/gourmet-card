#### 1-2. 一覧の選択モード（仕様書 4.5.3）
**入口**
- 上部バーに「選ぶ」ボタン。並びは 列数ボタン → 選ぶ → メニュー。列数ボタンと同じ控えめな形
- **375px 幅（iPhone SE・mini）でも1行に収まること**をスクリーンショットで確かめる。収まらない時は「選ぶ」を件数の行（並び順の左）に置き、報告に書く（既存ボタンの文言・大きさは変えない）

**選択モード中の画面**
- 上部バー：左「キャンセル」、題名の位置に「3店を選択中」（0店の時は「お店を選んでください」）。列数ボタン・「選ぶ」・メニューは隠す。キャンセルで選択を全部外し、普通の一覧へ
- タイルのタップで選ぶ／外す（**店ページは開かない**）。状態は `aria-pressed` で持つ
- タイルの見た目
  - 選んだタイル：写真を少し暗く（黒 25% 程度の膜）し、右上に塗りの丸＋白いチェック（色はアプリのアクセント色）
  - 選んでいないタイル：右上に白い縁の空の丸（薄い影で、明るい写真の上でも見える）
  - 3列・2列どちらでも崩れない。写真なしのタイルでも見える。店名・☆の見た目は変えない
- 「＋」は隠す。画面下に固定の帯（`env(safe-area-inset-bottom)` を考慮）に「3店を送る」ボタン。0店の時は押せない。帯がタイルの最後の行を隠さないよう、一覧の下に余白をとる
- 見えていない選択がある時（タブや条件で外れた店）は、帯に小さく「うち2店は今の表示の外」

**すべて選ぶ**
- 選択モード中もタブ・チップ・絞り込みパネル・並び順・「条件を解除」はそのまま使える。**タブや条件を変えても選択は残す**
- 件数の行に「表示中をすべて選ぶ」。表示中の店が全部選ばれている時は「表示中をすべて外す」（表示中の分だけ外す）。表示中が0件の時は出さない

**状態の持ち方**
- 選択モードは画面の中の状態。URL・履歴・設定は変えない。一覧のモジュール変数の記憶（店ページから戻った時の復元用）にも入れない

**送る**
- 「3店を送る」で工事8の送るシート（`SendSheet`）を開く。題名は「3店を送る」。準備は 1-1 の関数
- 店の順：タブに関係なく全店を**今の並び順**で並べた中での、選んだ店の順
- 送れた時（`onDelivered`＝共有の完了、または「ファイルとして保存」）は、シートが閉じた時に選択を外して普通の一覧へ戻る。タブ・条件・スクロール位置はそのまま
- 共有メニューを閉じた（AbortError）時・送らずにシートを閉じた時は、選択モードのまま・選択も残す
- 最後のバックアップ日時は記録しない（お裾分けなので）

**作り**
- B-3：選択の状態と部品は新しいファイルに置く（例 `src/components/select/`）。選択の計算（切替・表示中をすべて選ぶ／外す・表示外の数・送る順）は純粋関数にして `src/lib/` に置き、Vitest で固定する
- `HomeScreen.tsx` の変更は最小に（上部バーの切替、タイルのタップの切替、「＋」と帯の切替、件数の行のボタン）
- `ShopTile` の普通の一覧での動きは変えない。選択の表示を足すなら任意の props で

#### 1-3. e2e（新しい `e2e/select.spec.ts`）
1. **入口と基本**：「選ぶ」→「お店を選んでください」、「＋」が無い、「送る」が押せない → 2店をタップ →「2店を選択中」「2店を送る」→ もう一度タップで外れる → キャンセルで普通の一覧（タイルのタップで店ページが開く）
2. **店ページが開かない**：選択モード中のタップで URL が `#/` のまま
3. **表示中をすべて選ぶ**：県で絞り込む → すべて選ぶ → 件数が表示中の数 → 条件を解除 → 選択は残り、ボタンは「表示中をすべて選ぶ」に戻る。条件で外れた選択がある時「うち N店は今の表示の外」
4. **タブをまたぐ**：手札から1店・行きたいから1店 →「2店を選択中」
5. **送って取り込む**：3店を選ぶ → 送る → 準備 →「ファイルとして保存」→ 名前が `グルメカード_<先頭の店名>ほか2店.zip` → シートを閉じると選択モードが終わり、タブ・条件はそのまま → 別の端末で取り込む：「お裾分け（友人から）」「新しいお店 3件」→ 行きたい 3、店名・評価が同じ
6. **共有メニュー**（`navigator.canShare`／`share` を差し替え）：準備の後も `share` は呼ばれていない → 押すと File が1つ（`application/zip`、名前に「ほか」）→「送りました」→ 選択モードが終わる。AbortError の時は選択モードのまま・選択も残る。どちらも「最後のバックアップ」は記録されない
7. **1店だけ**選んで送ると、ファイル名が `グルメカード_<店名>.zip`
- 既存の単体 318件・e2e 60件・e2e:dist 5件がそのまま通ること（直した箇所があれば理由つきで報告）
