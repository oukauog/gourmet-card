#### 1-1. 見本切替の撤去と 4:5 × 重ね への固定
- 見本チップと保存処理を削除する：`src/dev/DevShopLookChips.tsx`・`src/dev/shopLook.ts`・`src/dev/devShopLook.css`、`ShopScreen` の `DevShopLookChips`（lazy）と `loadDevLook`、`look` の状態

#### 1-2. 写真なしの淡色6色の定義を1か所にまとめる
- 今は同じ6色が `home.css`（`.tile-nophoto[data-tone]`）と `carousel.css`（`.photo-band[data-tone]`）の2か所に書かれている。**色の値を1か所だけに置き**、両方がそれを使う形にする（CSS 変数にする・共通のファイルに切り出す等、方法は任せる。理由を報告）

#### 1-3. e2e の修正
- `e2e/shop.spec.ts` の「見本の4通り」のテストを、**固定後の見た目のテスト**に置き換える：写真枠の幅 390・左端 0・上端 0・高さ 487.5、バーが無い、浮いた戻るボタンが左上にあり最下部までスクロールしても同じ位置、押すと一覧に戻る、写真なしの店でも帯の上端 0 でボタンが乗る、見つからない店でもボタンと「一覧へ戻る」が重ならない
