## 7. 設計上の判断・迷った点

1. **既存の駅と同じ県・同じ名前の駅も足した（3件）**
   - 依頼のルールでは、「代表と違う名前」であれば、別のグループに同じ名前の駅があるかどうかは見ないので、足しています
   - 該当する3駅（いずれも同じ市に同じ名前の駅がもう1つある）
     - 仙台（地下鉄。あおば通のグループ。JR の「仙台」は別のグループ）
     - 野田（阪神。海老江のグループ。JR の「野田」は別）
     - 高井田（大阪メトロ。高井田中央のグループ）
   - この3つは候補で「仙台駅（仙台市）」が2つ並びます（名前・所在地が同じで見分けられない。工事7 報告 4.5 の吹田などと同じ）
   - 補足表と同じく「同じ県に同じ名前があれば足さない」にもできます（15章 1）
2. **足した駅の並びと id**
   - 駅マスタの中では、今までどおり県ごとに id（駅コード）の数字の順で並びます
   - 同じグループに同じ名前の行が複数ある時（同じ駅の複数路線）は、一番小さい駅コードの行の名前・県・住所を使いました
3. **「〈〉」と「（）」**
   - NFKC で「（）」は「()」になりますが、「〈〉」（U+3008/3009）は変わりません
   - そのため「〈」「〈」→「(」、「〉」「〉」→「)」に置き換えてから比べています（比較だけに使い、名前はそのまま持つ）
4. **「駅前」の表示名**
   - 「駅前」で終わる名前はそのまま（「王子駅前」「南富山駅前」、名前が「駅前」だけの駅も「駅前」）
   - 「駅前通」のように途中に「駅前」がある名前は、今までどおり「駅前通駅」
   - 既存のテストで「駅前」→「駅前駅」を確かめていた1か所だけ、期待値を変えました（8章）

## 11. 保留・質問

1. **同じ県に同じ名前が既にある別の名前の駅（仙台・野田・高井田の3駅）**
   - 今回は依頼のルールどおり足しました。そのため、候補に同じ表示が2つ並びます（7章1）
   - 足さない方がよければ、生成スクリプトに「同じ県に同じ名前があれば足さない」を1行足すだけで外せます
     - ただし、その駅を選んで登録した店が既にある場合は、外すと「（見つからない駅）」になります
     - 公開直後なので、外すなら早い方が安全です
2. 足した駅の id は駅コードです。原データの更新でグループの組み方が変わっても、同じ駅コードなら id は変わりません
   - ただし、原データの更新で「代表」と「別の名前」が入れ替わった場合の扱い（代表の id はグループコード、別の名前の id は駅コード）は、更新の時に回帰テストで気づける作りです（控えのファイルを更新ごとに作り直す運用）
