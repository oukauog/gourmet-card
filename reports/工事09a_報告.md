## 3. 「手札」のアイコン2案

**共通**
- 地はアクセント色 #d9480f（案B と同じ）で、端まで塗る（角丸・透過なし、文字なし）
- カードは白（170×230、角丸 20）に薄い影（下へ 4px、ぼかし 6、赤茶 35%）
- 3枚とも中央 80% の円の中に収めた（円を重ねて確認）
- **重ね順は奥から 寿司 → 焼肉 → ラーメン**。一番手前（見える面が一番広い）がラーメン
- **イラスト**（平塗り、色数は1つにつき4〜6色、細い線・小さな模様なし）
  - 各カードの上から大部分を占める淡い色の四角の上に描いた（白いカードの上で白いご飯などが消えないように）
  - **ラーメン**（淡いクリーム地）: 赤い丼（半円）と濃い赤の縁、橙のスープの楕円、太い黄色の麺の波、白いナルト（ピンクの点）、白いゆで卵（黄身）
  - **寿司**（淡い水色地）: 白いシャリ（灰青のふち）の上に、橙のサーモンと、太い斜めの薄橙の筋2本
  - **焼肉**（淡い桃色地）: 濃い灰の丸い網に、太い灰の棒3本、赤い肉2切れ（太いピンクの脂の筋）
- **60px で見分けるための工夫**
  - イラストを大きくした（カードの枠いっぱいに 1.22 倍で描き、カードの文字の線は外した）
  - 色の塊で見分ける（赤い丼＋黄色の麺、黒い網＋赤い肉、橙のサーモン＋白いシャリ）
  - 線はどれも太め（512px の絵で 8〜11px 以上）
  - 最初の試作はイラストが小さく、60px で何か分からなかったので、2回大きくし直した

## 4. 保存の保護を求める規則（`src/pwa/persist.ts`）

- **呼んだら記録する**: `navigator.storage.persist()` を呼ぶたびに、次の2つを設定に書く
  - `persistRequestedAt`（ISO 文字列）
  - `persistResult`（true なら `granted`、false なら `denied`、例外なら `error`）
- **呼ばない時**（記録もしない）: `persisted()` がもう true の時、`persist`・`persisted` の API が無い時
- **3つのタイミング**
  1. **起動時**（`App.tsx` の今の呼び出しのまま）: 店が1件以上なら求める
  2. **一覧を表示した時**（`ListBanner` から）: 読み込みが終わった時点で店が1件以上なら求める
  3. **「保護を求める」ボタン**（「この端末での保存」の欄）
     - 保護されていない時で、API がある時だけ出す
     - 店が0件でも押せる
     - 押すたびに求め、結果に合わせて保護の状態と結果の行を読み直す
     - 保護されたらボタンは消える
- **起動ごとに1回まで**（1 と 2 を合わせて）
  - モジュール変数 `askedThisRun` で覚える。店が1件以上の時に初めて true にするので、0件の間は何度呼んでも求めない
  - 確かめと記録は同じ処理の中で続けて行う（待ちを挟まない）。起動時と一覧がほぼ同時でも二重に求めない
  - 初めて開いた時（0件）は起動時も一覧も求めず、最初の店を登録して一覧に戻った時に1回求める（e2e で確認）
  - ボタンはこの制限の外です（押せば何度でも求める）
- **表示**
  - 「保護されています／保護されていません」の文言はそのまま
  - その下に小さく「最後に保護を求めた日時：9月28日 10:12・許可されませんでした」
    - 日本時間（時は0を付けない、分は2桁）
    - `granted`＝許可されました／`denied`＝許可されませんでした／`error`＝失敗しました
  - 一度も求めていなければ、この行は出さない

**スクリーンショット**
- `storage-not-protected.png`: 保護されていない（「許可されませんでした」の行と「保護を求める」）
- `storage-protected.png`: 保護されている（「許可されました」の行、ボタンなし）
