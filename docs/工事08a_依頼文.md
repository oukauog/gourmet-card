### 1. やること

#### 1-1. 拡張子を `.zip` に固定
- `src/lib/cardFileType.ts`：送るファイルは **`.zip`・MIME `application/zip` だけ**にする（`.gcard` の選択肢と既定値の仕組みを外す）
- ファイル名：1店 `グルメカード_<店名>.zip`、全店 `グルメカード_バックアップ_YYYYMMDD-HHmm.zip`
- **取り込みは今までどおり拡張子を見ない**（工事8の間に作った `.gcard` のファイルもそのまま取り込めること）

#### 1-2. 試験用の切替を撤去
- `src/components/share/FileTypeTrial.tsx` をファイルごと消す。`DataScreen.tsx`・`ShopScreen.tsx` など、呼んでいる所と `data.css` の試験用の CSS を消す
- 工事8で lint の警告を止めるために書いたコメント（`currentCardFileType` の分）が不要になれば一緒に消す
- 花井さんの iPhone に残る `localStorage` の値は**消しに行かない**（読まなくなるだけで害がないため）。報告にキー名を書く

#### 1-3. 取り込みの案内（文言だけ）
- 「バックアップと取り込み」画面の取り込みの説明を次の趣旨にする（短く。2行程度）
  - 「友だちから届いたファイルは、LINE なら開いて『ファイルに保存』、AirDrop なら『ファイル』アプリに入ります。選ぶ画面の『最近使った項目』か、検索で『グルメカード』と入れると見つかります」
- 取り込みで「グルメカードのファイルではありません」になった時、そのエラー文の**下に小さく**「『ファイル』アプリで .zip をタップすると中身のフォルダができます。取り込むのはフォルダの中ではなく、.zip のファイルそのものです」を出す
  - エラー文そのもの（`cardFormat.ts` の文言）は変えない（既存テストがそのまま通るように）

#### 1-4. テスト
- e2e `share.spec.ts` の試験用の切替のテスト（8件目）を、次の確認に置き換える
  - 送るファイル名が `.zip`、共有に渡る File の MIME が `application/zip`（1店・全店とも）
  - `.gcard` という名前のファイル（中身は同じ ZIP）も取り込める
  - 画面に試験用の切替が無い
  - ZIP でないファイルの時、上の案内が出る
- ほかの e2e で `.gcard` を前提にしている所があれば `.zip` に直す（どこを直したか報告）
- 単体テストで拡張子を扱っているものがあれば同様に。**往復テストは中身を変えない**
- 既存の単体 318件・e2e 59件・e2e:dist 5件が（置き換えたもの以外）そのまま通ること

#### 1-5. 公開する
- 全部通り、`work/08a-zip` にコミット・push してから、作業ツリーがクリーンな状態で `npm run deploy`。公開した版を報告
