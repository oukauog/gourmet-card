## 工事7：駅マスタ・市区町村マスタ（最寄り駅・市の入力、駅から県・市の自動補完、場所の絞り込みに市・駅）

あなたは「グルメカード」の実装役です。今回は、全国の**駅**と**市区町村**の一覧をアプリに同梱し、次の3つを足す工事です。
- 登録・編集フォームに**最寄り駅**（文字入力＋候補）と**市**（選択式）
- 駅を選んだら、空いている県・市を自動で埋める
- 店ページに最寄り駅を表示し、一覧の場所の絞り込みに**市・駅**の段を足す

まず次を読んでから着手してください。

- `docs/01_仕様書.md`（**v0.11**。特に 3.2 店の項目、**3.5 駅マスタ・市区町村マスタ（全面改訂）**、3.7 データ層、4.1.1 絞り込み、4.2.1 フォーム、**4.2.2 工事7の決定**、4.3 店ページ）

#### 1-2. マスタの読み込みと純粋関数（新規ファイル）
- マスタの JSON は**必要になった時に別ファイルとして読み込む**（`import()` 等）。一覧を開いただけで駅マスタを読まない（店に駅が付いている時・フォームを開いた時など、要る時だけ）。一度読んだら使い回す
  - 本番ビルドで、最初に読む JS に駅名が入っていないこと（1-8 の grep で確認）
- 純粋関数を `src/lib/` の新規ファイルに置き、Vitest で固定する（名前・分け方は任せる）
  - **駅の候補**（入力文字列・選択中の県 → 最大8件）
    - 入力と駅名の両方を NFKC＋空白の除去で正規化。「ヶ」「ケ」は同じとみなす。入力の末尾の「駅」は外す
    - 1文字から候補を出す。空の入力では出さない
    - 並び：前方一致 → 部分一致。それぞれの中で、選択中の県の駅を先 → 駅名の短い順 → 同じなら県の順（決定的に）
  - **駅の表示名**：駅名＋「駅」（「富山駅」）。名前が「駅」「ステーション」で終わる時は付けない
    - 候補・パネル用の名前：同じ名前の駅が別の県にもある時だけ「府中駅（東京都）」。同じ県に同名がある時は「〇〇駅（〇〇市）」
  - **自動補完**（今の県・市と選んだ駅 → 新しい県・市）：県が空なら駅の県を入れる。市が空で、県が駅の県と同じなら駅の市を入れる。**入っている値は上書きしない**
  - 市の一覧（県 → 市区町村名の配列）
  - マスタに無い駅 ID を渡しても例外にしない（「見つからない」を返す）

#### 1-3. 登録・編集フォーム
- 項目の並び（仕様書 4.2.2）：写真 → 店名 → 手札/行きたい → 評価 → ジャンル → 使い道 → **最寄り駅 → 県 → 市** → エリア → GoogleマップURL → メモ → 出典表記
- **最寄り駅**：文字入力＋候補の一覧（工事5のタグ入力の候補と同じ感触でよい。iPhone のキーボードの開閉に気をつけた点は報告）
  - 候補の各行は「駅名＋所在地（小さく「富山県富山市」）」
  - 選ぶと「富山駅」＋「×」の表示になる。× で外す（県・市は残す）
  - ひらがな・カタカナだけの入力で候補が無い時は「漢字で入力すると候補が出ます」（無料版にカナが無いため）
  - マスタを読み込み中は入力できない（短く「読み込み中…」）。読み込みに失敗しても、フォームの他の項目は使える
  - 保存済みの駅 ID がマスタに無い時は「（見つからない駅）」＋「×」
- **県**：今のまま（47択）。**県を変えたら市を空にする**（フォームの中で。駅は触らない）
- **市**：選択式。候補は選んだ県の市区町村（団体コード順）＋先頭に「選択しない」。県が未選択の間は選べない（押せない見た目）。一覧に無い値（見本データ等）は先頭に残す（県の選択と同じやり方）
- 駅を選んだ時は 1-2 の自動補完で県・市を埋める
- 「変更を破棄しますか？」の判定に市・駅を含める
- **保存**：フォームの県・市・駅をそのまま保存する。`src/db/saveShopForm.ts` の「県が変わったら市を消す」は**フォームへ移したので外す**（新規登録でも市・駅を保存する）。この変更に合わせて既存テストを直す箇所は表にして報告
- **出典表記**：フォームの最下部（メモの下。下部固定の保存ボタンに隠れない位置）に小さな灰色の文字で次の2行
  - `駅データ：駅データ.jp（https://ekidata.jp/）`
  - `市区町村：「全国地方公共団体コード」（総務省）（https://www.soumu.go.jp/denshijiti/code.html）を加工して作成`
  - リンクにするかは任せる（するなら別タブ）

#### 1-4. 店ページ
- 場所の欄を上から「富山県 富山市」→「富山駅」（最寄り駅）→ エリア にする。駅の表示名は 1-2 の短い方（「富山駅」）
- 駅だけ入っている店でも場所の欄を出す。マスタに無い駅 ID は出さない（他が空なら欄ごと出さない）

#### 1-5. 一覧の絞り込み（場所パネルに市・駅）
- 条件に市と駅を足す（`src/lib/shopFilter.ts` を拡張してよい）
  - 市：**県と組で判定**（東京都府中市と広島県府中市は別）。選んだ市の**どれか**
  - 駅：選んだ駅の**どれか**
  - 種類をまたぐと「かつ」（今までどおり）
- 場所パネルの段：**県 → 市 → 駅 → エリア**（`FilterPanel.tsx` の `sectionsOf` の `place` に足す）。候補が無い段は出さない
  - 候補は今までどおり「今のタブの店」で1件以上・件数つき・件数の多い順
  - **県を選んでいる時は、市・駅の候補をその県のものだけにする**（選択中のものは残す）
  - 市の候補名：同じ名前の市が候補に2つ以上ある時だけ「府中市（東京都）」
  - 駅の候補名：1-2 の候補・パネル用の名前
- チップ「場所」の数え方は 県 → 市 → 駅 → エリア の順に合わせて数える（「富山県 ほか2」）
- 駅の名前が要るので、今のタブのどれかの店に駅が付いている時だけ駅マスタを読む。読み終わるまで駅の段は出さなくてよい
- 既存の条件の判定・候補の並び・チップの文字は変えない（既存テストが通ること）

  - 保存：新規・編集で市・駅が保存される、県を変えずに市だけ変えられる
- **e2e（スマホ幅 390×844。新規 `e2e/station.spec.ts`）** 最低限：
  - 「富山」と入れる → 候補に富山駅（富山県富山市）→ 選ぶ → 県＝富山県・市＝富山市が入る → 保存 → 店ページに「富山県 富山市」「富山駅」

  - 「黒部宇奈月温泉」（補足の駅）が選べて、富山県・黒部市が入る
