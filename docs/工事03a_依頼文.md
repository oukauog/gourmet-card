## 工事3a：見本切替の撤去と A2 への固定・列数ボタンの表示変更・小画像 600px・不要 CSS の整理

あなたは「グルメカード」の実装役です。工事3の続き（小修正）です。まず `CLAUDE.md`、`docs/01_仕様書.md`（**v0.6**。特に 3.3 写真・3.9 ルーターと一覧画面の実装決定・4.1 一覧画面）、`reports/工事03_報告.md`（自分の前任者の報告。特に 5章のタイルと 11章の保留）を読んでから着手してください。

花井さんが iPhone 実機で見本を判定しました。結果は次のとおりです。
- デザインは **A2**（隙間 2px・角丸なし・端まで）が「圧倒的」。A1 は不採用
- 列数は「甲乙つけがたい」ので、**2列/3列の切替ボタンをそのまま本機能として残す**（固定しない）。既定は 3列のまま
- 文字・隙間・写真なしタイルの色・☆は問題なし。写真の甘さも気にならない
- 列数ボタンは「今の列数」ではなく**「押した結果」**（例「2列にする」）を表示する方がよい
- 報告 11章の保留への回答：小画像は長辺 **600px** に上げる（登録済み写真は作り直さない）／`.dev-bar` の CSS と旧仮ホームの CSS は削除してよい

### 1. やること

#### 1-1. 見本切替（A1/A2）の撤去と A2 への固定
- A1/A2 のチップ、`TileVariant` の状態、`src/dev/sampleVariant.ts`（sessionStorage への保存）を削除する
- `HomeScreen` の `tiles-${variant}` クラスを無くし、A2 の見た目を**既定のスタイル**にする（`home.css` の `.tiles-a1` 側の定義を削除し、`.tiles-a2` の内容を無条件のスタイルに畳み込む）。見た目が A2 のまま変わらないこと（e2e で `.tile-grid` の `gap` が 2px、`border-radius` が 0 であることを確認する）
- 見本バー（`DevSampleBar`）は「見本用に増やす」「見本データを消す」の**2ボタンだけ**にして残す（`import.meta.env.DEV` 限定のまま。後の工事の確認用）。**できれば** `DevSampleBar` を `React.lazy(() => import('../dev/DevSampleBar'))`＋`Suspense` で読み込み、本番ビルドから見本バーの JS と CSS（`.dev-bar`）が完全に消えるようにする。難しければ `.dev-bar` の CSS が本番に残ることは許容し、報告書に書く
- 見本の撮影専用の仕組み（`npm run shots`、`e2e/playwright.shots.config.ts`、`e2e/samples.shots.ts`）は役目を終えたので削除する。`reports/工事03_見本/*.png` は記録として**残す**

#### 1-2. 列数ボタンの表示を「押した結果」に
- ボタンの文字を `「{次の列数}列にする」`（3列表示中なら「2列にする」、2列表示中なら「3列にする」）にする。アイコンも**次の列数**のグリッドを描く
- `aria-label` は今と同じ趣旨でよい（「2列表示に切り替え」等）
- e2e（`home.spec.ts` の列数テスト）を新しい文字に合わせて直す

#### 1-3. 小画像を長辺 600px に（`src/lib/imageSizes.ts` の変更を**この1ファイルだけ許可**）
- `imageSizes.ts` の小サイズの長辺を **400 → 600** にする（JPEG 品質 0.80 は変えない。大サイズも変えない）
- 影響するテストを新しい寸法に合わせる：
  - `e2e/register.spec.ts`：fixture 1（3000×2000）の small は **600×400**、fixture 2（800×1200 PNG）の small は **400×600**、fixture 3（EXIF）の small は **450×600**（大の寸法はすべて今のまま）
  - 単体テストで 400 を前提にしている箇所があれば同様に直す（`fitLongSide` 自体のテストは純粋関数なので変更不要のはず）
- **登録済みの写真の small は作り直さない**（作り直す機能も作らない。試し登録のデータだけなので、花井さんが消して登録し直す）
- 報告書に、PC の Chromium で fixture 3枚を通した **small の寸法とファイルサイズ（KB）** を工事2報告 4章と同じ表形式で書く（400px の時との比較のため）

#### 1-4. 不要 CSS の整理
- `src/styles/app.css` から旧仮ホームのスタイル（`.shop-rows`・`.shop-row`・`.shop-row-thumb`・`.shop-row-thumb-empty`・`.shop-row-body`・`.shop-row-name`・`.shop-row-meta` など）を削除する。**削除前に `src/` と `e2e/` を grep して、どこからも参照されていないことを確認**し、その結果を報告書に書く
- `.btn-danger-text` など、仮ホームだけが使っていたクラスも同様に確認して整理する（他で使っていれば残す）
- 登録画面・店ページの見た目が変わらないこと（e2e が通ること）
