  2. **店名**（大きめ・太字。長い店名は折り返す）

#### 1-3. 見本 2×2 の切替（DEV 限定。工事3の A1/A2 と同じ考え方）
- 軸は2つ：写真の縦横比 `1:1` / `4:5`、上部 `バー` / `重ね`
- 見た目の違いは**店ページ最上位要素のクラスだけ**で出す（例：`shop-ratio-1x1` / `shop-ratio-4x5`、`shop-head-bar` / `shop-head-overlay`）。TSX 側の分岐は最小に
- **重ね**：上部のバーを出さず、写真を画面の最上部から表示。左上に半透明の丸い「←」戻るボタンを重ね、**スクロールしても左上に残る**（`position: fixed`、`env(safe-area-inset-top)` を考慮）。写真なしの店でも帯の上に同じボタンが乗ること
- **バー**：今の `.topbar`（← 戻る）をそのまま使う
- 切替チップ（「写真 1:1 / 4:5」「上部 バー / 重ね」）は店ページの削除ボタンの上に、見本バーと同じ点線枠の見た目で置く。選択は `sessionStorage` に保存（読み書きは try/catch で囲む）し、どの店を開いても同じ見本で見られるようにする
- チップの部品と保存処理は `src/dev/` に置き、**工事3a の見本バーと同じく `React.lazy` で読み込んで本番ビルドから完全に消す**。本番の既定は **1:1 × バー**（判定までの仮）
- 不採用になる側の CSS が本番に残るのは許容（判定後の工事4a で消す）。報告書にその旨を書く
