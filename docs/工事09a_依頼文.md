### 1. やること

#### 1-1. 「手札」のアイコン（仕様書 4.6）
- 新しい元の絵を SVG で `data-src/icons/` に2つ置く
  - **扇形**（`hand-fan.svg`）：3枚のカードを、トランプを手に持った時のように下の1点を中心に扇に開く。隣のカードと約半分ずつ重なる
  - **ずらし**（`hand-offset.svg`）：3枚のカードを少し傾け、横に約半分ずつずらして重ねる
- 共通の条件
  - 地の色・白いカード（角丸・薄い影）は案B と同じ
  - 3枚のカードに、食べ物のイラストを1つずつ載せる。**ラーメン**（丼・麺・ナルトなど）、**寿司**（握り）、**焼肉**（網と肉）。一番手前（見える面が一番広い）はラーメン
  - イラストは平塗りで色数を少なく。**ホーム画面の実寸（約 60px）でも何の食べ物か分かる**ことを優先する（細い線・小さな模様は使わない）
  - 正方形で端まで塗る（角丸・透過にしない）、文字は入れない。大事な部分は中央 80% の円に収める（maskable）
- `scripts/make-icons.mjs` の引数を `fan`／`offset` に変える（既定は **`fan`**）。案A〜C の SVG（`icon-a.svg`・`icon-b.svg`・`icon-c.svg`）とその選択肢は消す
- `npm run icons` を実行し、`public/` の PNG 4つと `favicon.svg` を扇形に置き換える（ファイル名・大きさ・manifest は変えない）
- **見本画面**（DEV 限定、工事9 の `IconSamples`）は、案A〜C の代わりに扇形・ずらしの2つを出す。見え方（約 60px・明るい壁紙と暗い壁紙・ほかのアプリの四角・180px）は工事9 と同じ。見本画面そのものはアイコンが決まるまで残す（撤去は工事10）

#### 1-2. 保存の保護の求め直し（仕様書 4.6。花井さん決定）
- 保護を求める処理（`src/pwa/persist.ts`）を、次の形にまとめる
  - `navigator.storage.persist()` を呼んだら、**呼んだ日時と結果を設定に記録する**：`persistRequestedAt`（ISO 文字列）と `persistResult`（`granted`｜`denied`｜`error`）。`persist()` が true なら `granted`、false なら `denied`、例外なら `error`
  - `persisted()` がもう true の時・API が無い時は呼ばない（記録もしない）
  - 設定キー2つを `types.ts` の `SettingsMap` と `settings.ts` の検証に足す（既存キーの扱いは変えない）
- 求めるタイミングを3つにする
  1. 起動時（今のまま。店が1件以上で、保護されていない時）
  2. **一覧を表示した時**：店が1件以上で、保護されていなければ求める。**起動ごとに1回まで**（モジュール変数で覚える。起動時に求めた時は、一覧では求めない）。初めて開いた時は0件なので、最初の店を登録して一覧に戻った時に求めることになる
  3. **「保護を求める」ボタン**：「この端末での保存」の欄に、保護されていない時だけ出す（API が無い時は出さない）。押したら求めて、結果に合わせて表示を読み直す。店が0件でも押せる
- 「この端末での保存」の欄に、最後に求めた日時と結果を小さく出す：「最後に保護を求めた日時：9月28日 10:12・許可されませんでした」（`granted`＝許可されました／`denied`＝許可されませんでした／`error`＝失敗しました）。一度も求めていなければ出さない。日時は日本時間
- 「保護されています／保護されていません」の文言はそのまま
- B-3：変更は工事9 で作ったファイル（`src/pwa/`・`src/components/pwa/`・`src/components/banner/`）を中心に。`HomeScreen.tsx`・`App.tsx` を触るなら呼び出しだけにする

#### 1-3. テスト
- 単体（Vitest）：記録（granted／denied／例外で error／もう保護されている時は呼ばない・記録しない／API が無い）、表示の文（結果3種・日本時間の日時）
- e2e（`e2e/pwa.spec.ts` に足す。`navigator.storage.persist`・`persisted` は `addInitScript` で差し替える）
  1. 店0件で起動 → `persist` は呼ばれない → 店を1件登録して一覧に戻る → `persist` が1回呼ばれる → 一覧と店ページを行き来しても2回目は呼ばれない
  2. 保護されていない時：「保護を求める」ボタンがある → 押す（結果 false）→「許可されませんでした」と日時。結果 true に差し替えて押す →「保護されています」になり、ボタンが消える
  3. `persist` が例外 →「失敗しました」
  4. 一度も求めていない時は、最後の結果の行が出ない
- e2e:dist：manifest のアイコン PNG がすべて 200 で、中身が扇形に替わっている（ファイルの大きさか hash が工事9 と違う）ことを確かめる
- 既存の単体 338件・e2e 79件・e2e:dist 8件がそのまま通ること（アイコンに関わるテストで直した箇所があれば理由つきで報告）
