# data-src — 駅マスタ・市区町村マスタの原データ

アプリに同梱する駅と市区町村の一覧（`src/data/stations.json`・`src/data/cities.json`）は、このフォルダの原データから `npm run geo-data` で作ります（工事7、仕様書 3.5）。アプリは原データを直接は読みません。

## 置いてあるもの

| ファイル | 中身 | 出典 |
|---|---|---|
| `ekidata/station*.csv` | 駅データ（無料版）。1つだけ置く | 駅データ.jp（https://ekidata.jp/） |
| `soumu/000925835.xlsx` | 全国地方公共団体コード（令和6年1月1日更新） | 総務省（https://www.soumu.go.jp/denshijiti/code.html） |
| `extra-stations.csv` | 無料版に無い新幹線だけの駅（`id,name,prefecture,city`、UTF-8） | 相談役が作成 |

## 利用条件と出典表記

- **駅データ.jp**：商用・非商用とも利用可。加工の有無にかかわらず第三者に提供できる（加工しない提供は無償に限る）。出典表記の義務は無いが、規約で明記・リンクを歓迎しているので表記する
- **総務省「全国地方公共団体コード」**：公共データ利用規約（第1.0版。CC BY 4.0 互換）。**出典表記が必須**。加工しているので「〜を加工して作成」と書く
- アプリの登録・編集フォームの最下部に次の2行を出している
  - 駅データ：駅データ.jp（https://ekidata.jp/）
  - 市区町村：「全国地方公共団体コード」（総務省）（https://www.soumu.go.jp/denshijiti/code.html）を加工して作成

## 生成のしかた（要点）

- 市区町村：Excel の1枚目（都道府県・市区町村）。県の行と、北方領土の6村（色丹村〜蘂取村）は除く。政令市の区の表は使わない（市まで）。1,741件（1,718市町村＋23特別区）
- 駅：運用中（`e_status` が 0）の行を駅グループコード（`station_g_cd`）で1駅にまとめる
  - 名前・県・住所は、グループコードと同じ駅コードの行（運用中なら）。無ければ名前の一番短い行
  - 市は住所の県名の後ろと、その県の市区町村名との最長一致。合わなければ先頭の「〇〇郡」を1つ外してもう一度
- 補足表の駅は、同じ県・同じ名前の駅が無い時だけ足す。補足表の市が市区町村マスタに無ければ止まる
- 同じ原データからは毎回同じ JSON ができる

## 原データの更新手順（花井さん）

1. 駅データ.jp にログインし、新しい「駅データ」無料版 CSV をダウンロードする
2. `data-src\ekidata\` の古い CSV を消して、新しい CSV を置く（**CSV は1つだけ**。ファイル名は変えなくてよい）
3. 実装役に「駅データを更新したので `npm run geo-data` をしてテストして」と頼む
   - 実装役は `npm run geo-data` → 件数・市が決まらない駅の数を確かめる → `npm test` と `npm run e2e` → 原データと生成物を一緒にコミットする
4. 総務省の Excel を新しくする時は、`scripts/build-geo-data.mjs` のファイル名も合わせて変える（実装役の工事）
