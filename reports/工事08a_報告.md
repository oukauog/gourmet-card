## 3. テストの置き換え（`e2e/share.spec.ts`）

| 箇所 | 変更前 | 変更後 |
|---|---|---|
| 1件目「send one shop …」 | 保存したファイル名 `グルメカード_白えび亭.gcard` | `グルメカード_白えび亭.zip` |
| 2件目「back up every shop …」 | バックアップのファイル名 `….gcard` | `….zip` |
| 5件目「share sheet: …」 | 名前「… with one .gcard File …」、共有に渡る File は `グルメカード_共有する店.gcard`・`application/octet-stream` | 名前「… with one .zip File …」、`グルメカード_共有する店.zip`・`application/zip` |
| 8件目「trial switch: …」 | 試験用の切替（`.gcard` 既定 → `.zip` を選ぶ → 再読み込みで残る → `.zip` の送信・保存・取り込み） | **置き換え**（下の2件） |

**置き換えた2件**
1. 「.zip only: …」
   - 「バックアップと取り込み」画面に試験用の切替（見出し・`.gcard`・`.zip` の選択肢）が無い。新しい取り込みの説明が出ている
   - 全店のバックアップと1店を共有メニューで送ると、渡る File が `グルメカード_バックアップ_YYYYMMDD-HHmm.zip` と `グルメカード_ZIPの店.zip`、どちらも `application/zip`
   - 保存したファイル名も `.zip`
   - 同じ中身を **`.gcard` という名前**にしたファイルを別の端末で取り込める（「新しいお店 1件」→「1件取り込みました」）
2. 「not a card file: …」
   - ZIP でないファイルで、エラー文「グルメカードのファイルではありません」（変わらない）の**下に**案内が出る
   - 案内の文字はエラー文より小さい（12px）

- 取り込みのテストで使う名前には `.gcard` を残しています（`not-a-card.gcard` と上の2件目の1のファイル）
- ほかの e2e・e2e:dist に `.gcard` を前提にした所はありませんでした
